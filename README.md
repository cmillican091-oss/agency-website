# AI Mission Control Dashboard

A full-screen futuristic AI operations center built with Next.js, React, Tailwind CSS, TypeScript, Framer Motion, Recharts, and shadcn/ui patterns.

## Features

- Dark cyberpunk Mission Control experience
- Live-updating agent rooms in a digital building view
- Agent detail drawer with logs and activity history
- Revenue analytics dashboard
- Task queue manager
- Activity feed and alert monitoring
- VPS health and integration status panels
- Responsive desktop and mobile layout

## Tech Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4
- Framer Motion
- Recharts
- shadcn/ui-style component structure

## Getting Started

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Validation

```bash
npm run lint
npm run build
```
